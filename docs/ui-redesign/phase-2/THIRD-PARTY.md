# Tài nguyên của bản mẫu Phase 2

- Be Vietnam Pro: tải bốn weight 400/500/600/700 từ Google Fonts, CSS nguồn `https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;500;600;700&display=swap`; tệp font được lưu trong `fonts/`. Giấy phép SIL Open Font License1.1 đi kèm tại [fonts/OFL.txt](fonts/OFL.txt), lấy từ repository google/fonts, `ofl/bevietnampro/OFL.txt`. Không thay tên font hoặc chỉnh file font.
- Lucide: tập icon được trích từ gói Lucide1.8.0 có sẵn trong runtime; giữ nguyên node paths, đóng gói nhỏ trong `prototype/icons.js`; ISC license tại [prototype/LUCIDE-LICENSE](prototype/LUCIDE-LICENSE). Không tải icon CDN khi xem prototype.
- MathJax: tham chiếu thư viện local của dự án, `static/vendor/mathjax/`; không sao chép hoặc thay đổi thư viện trong Phase 2.
- Logo LinhEdu: tham chiếu `static/images/logo-transparent.png` hiện có; không tạo logo mới hoặc chỉnh dữ liệu ảnh.
- Tất cả tên lớp, người dùng, câu hỏi và số liệu trên prototype là minh họa, không lấy từ database.
